# AGENTS.md - Documentation Conventions

## Format

- Write in Markdown.
- If a diagram is needed, use Mermaid within Markdown.
- Include blank lines after section headings and around code fences.
- Never use "em-dashes" or "smart-quotes", just use plain ASCII dashes and quotes.
- Prefer bullet lists to numbered lists.

## When Making Changes

- Consider whether existing docs need to be updated or deprecated.
- Update `./plans/README.md` if priorities shifted.
- Create an ADR in `./decisions/` if an architectural decision was made.
- Observe and respect numbering of files.

## When Creating New Content

- Check existing docs first -- don't duplicate what's already written.
